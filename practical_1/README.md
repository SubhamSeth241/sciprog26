To compile each file, use:



gcc -o filename filename.c -Wall



where "filename.c" is the name of the file where code is written, and "filename" is the output file's name after compiling.



"helloworld.c" contains just initial coding to say hello to others.



"printing.c" demonstrates the printing procedure of results, numbers, or anything you want to show while compiling.



"scanning.c" determines whether a number is even or odd for 2 positive numbers and, if it is negative, indicates that it is negative.
