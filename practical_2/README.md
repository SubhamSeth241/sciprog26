To compile each file, use:



gcc -o filename filename.c -Wall



where "filename.c" is the name of the file where code is written, and "filename" is the output file's name after compiling.



**"Numconversion.c"** converts a base-10 integer number to a binary integer number.



**"Numconversion1.c"** converts a base-10 integer number to a binary integer number and counts the number of digits.



**"Sumdiff.c"** demonstrates the addition of a series in two different orders, i.e., 1) starting from the first number/function of the series and 2) starting from the last number/function of that series, and the difference between the two summation results. **(standard number of digits, i.e., 6 digits after the decimal)**



**"Sum\_diff1.c"** demonstrates the addition of a series in two different orders, i.e., 1000) starting from the first number/function of the series and 2) starting from the last number/function of that series, and the difference between the two summation results. **(20 digits after the decimal)**
