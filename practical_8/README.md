To compile each file, use:



gcc -o filename filename.c -Wall



where "filename.c" is the name of the file where code is written, and "filename" is the output file's name after compiling.



**"GCD.c"** represents the process of finding the Greatest Common Divisor (GCD) of two non-zero integers by using the Euclidean algorithm. **Here, in the same code, two different functions are used to calculate the GCD of two integers, a and b, provided by the user**. One function is used as an **iterative function** using pseudocode, as mentioned in the question, i.e., a while loop. And the other function is used as a **recursive function** by using the formula provided in the question, i.e. an if-else loop. It is also stated here that if the numbers are negative, the resulting GCD should be positive.



**"GCD\_random.c"** represents the process of finding the Greatest Common Divisor (GCD) of two non-zero random integers by using the Euclidean algorithm. **Here, in the same code, two different functions are used to calculate the GCD of two randomly generated positive integers, a and b**. One function is used as an **iterative function** using pseudocode, as mentioned in the question, i.e., a while loop. And the other function is used as a **recursive function** by using the formula provided in the question, i.e. an if-else loop. Here, a GCD\_random.txt file will be generated after compilation; it is included in the GCD-random.c program, and the generated file contains the GCD results of two numbers.
